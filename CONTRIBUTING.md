# Contribuindo para o NIST CSF 2.0 Navigator

Obrigado pelo interesse em contribuir!

## Como contribuir

1. Fork o repositório
2. Crie uma branch: `git checkout -b feature/minha-contribuicao`
3. Faça suas alterações
4. Commit: `git commit -m 'feat: descrição da contribuição'`
5. Push: `git push origin feature/minha-contribuicao`
6. Abra um Pull Request

## Áreas de contribuição

- Correção ou aprofundamento de conteúdo técnico
- Novos mapeamentos de frameworks
- Melhorias de acessibilidade
- Tradução para outros idiomas
- Novas funcionalidades

## Padrões

- TypeScript para todo código
- Tailwind CSS para estilos
- Dados separados dos componentes visuais
- Conteúdo tecnicamente correto e referenciado
